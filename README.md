# GRIT

매일 조금씩, 기어이 해낸다.

개인용 Android 자료해석 연습 앱. Flutter 3.41.7 / Dart 3.11.5. 서버, 로그인, 광고, 외부 패키지 없이 동작한다.

## 실행 흐름

세트 선택 → 시작과 동시에 새 문제 생성 및 시간 측정 → 입력/탭으로 풀이 → 완료 → 자동 채점 및 누적 저장.

- 덧셈·뺄셈: 표 5개, 빈칸 7/8/7/8/10개, 총 40개 채점.
- 곱셈: 곱 비교 8개 + 분수 비교 10개, 총 18개 채점.
- 나눗셈: 분수 4개 정렬 5개 + 분수 비교 10개, 총 15개 채점. 정렬은 전체 순서가 맞아야 정답.
- 표 입력: 한 화면에 표 전체·합계·앱 숫자패드를 표시. 가로/세로 스크롤 없이 답칸 탭, 음수 전환, 한 자리/전체 지우기, 이전/다음 빈칸, 이전/다음 표 이동. 가로 화면 및 폭이 충분한 펼친 폴더블에서는 표와 숫자패드를 좌우 배치. 실제 가용 폭 640dp 이상 또는 폭 560dp 이상인 가로형 창에서 분할하고, 숫자패드 폭은 240~320dp로 제한. 좁은 창의 입력 영역은 최대 480dp. 접힘/펼침 시 선택한 칸·답안·문제 위치·시작 시각 유지.
- 계산 메모: 항목명 행·구분 열을 제거한 자리에 오른쪽 가로 메모 열과 아래쪽 세로 메모 행을 배치. 합계 숫자는 유지하며 굵은 경계로 구분. 연한 파란색 메모칸을 탭해 숫자패드로 입력하고, 답칸을 탭해 답안 입력으로 복귀한다. 메모는 채점/응답 수에서 제외하며 풀이 중 메모리에 유지하고 완료 기록에 함께 저장한다.
- 비교/정렬: 선택 후 다음 문항으로 이동. 이전 문제/전체 문제 목록에서 수정 가능.
- 미응답 제출 확인. 채점 전 정답 피드백 없음. 실제 경과시간 기록, 오답 시간 벌점 없음.
- 일시정지·이어풀기 없음. 다른 앱으로 잠깐 전환해도 시작 시각 기준 시간은 계속 흐른다. 연습 화면을 나가려면 진행 폐기를 확인하며, 나가기 또는 프로세스 종료 시 미완료 문제/답안/메모는 사라진다. 완료·나가기 확인 창에서도 타이머는 계속 흐른다.
- 진행 중 연습 그만두기는 별도 확인하며 기존 완료 기록을 지우지 않는다.

## 자동 생성 규칙 v1

문제은행을 사용하지 않는다. 새 연습마다 새 난수 seed로 숫자/가림/배치를 생성하고 조건을 검사한다. seed와 실제 생성 문제를 모두 저장한다. 따라서 향후 생성기 변경 후에도 과거 문제 복습이 유지된다.

### 표

본문 크기: 3×3, 4×4, 3×3, 4×4, 5×6. 본문 정수 범위: 10~99, 0~59, -50~49, -30~29, -10~29. 합계는 실제 계산값이다. 뒤 3개 표는 양수/음수를 함께 포함한다. 가로 또는 세로 식의 미지수가 하나인 칸들을 동시 해결하는 반복이 2~4회에 끝나야 출제한다. 풀 수 없는 가림은 폐기한다.

### 곱 비교

정수 1000~10099 × 소수 1.0~99.9. 두 인수의 대소 방향은 서로 반대. 상대 차이는 abs(L-R)/max(L,R), 10~25%. 소수는 10배한 정수로 정확히 비교한다.

### 분수 비교

분자/분모 10~349, 약분하지 않음. 정확히 같은 값 제외. 상대 차이는 0 초과~14% 미만. 0~1%/1~5%/5~10%/10~14% 구간을 12/32/30/26% 확률로 선택한다. 교차곱으로 정답을 계산한다. 동일 분자/분모 허용.

### 분수 정렬

앞 3개 문항 분자/분모 10~349, 뒤 2개 10~999. 각 분수값 0.35~2.0. 최대/최소 상대 차이 17~28%, 이웃한 값 차이 3.5~14%. 같은 값 제외. 제시 순서를 섞는다.

위 범위는 제공된 예시의 통계를 바탕으로 합의한 구현 규칙이며 원본 난수식을 복원했다는 의미는 아니다.

## 저장 및 기록 관리

- 앱 내부 `grit_records.json`에 Android AtomicFile로 저장하며 쓰기를 직렬화한다.
- 완료한 세트의 날짜/시각, 종류, 실제 경과 초, 문제, 답안, 계산 메모를 보존한다. 미완료 연습은 디스크에 기록하지 않으며 이전 버전의 active 필드는 복구하지 않는다. 메모 필드가 없는 이전 기록도 읽을 수 있다.
- 두 메인 탭의 공통 설정에서 `기록 초기화`를 누르면 확인 후 모든 완료 기록과 메인 누적 통계를 함께 초기화한다. 필터와 무관하게 전체 완료 기록이 대상이다.
- 초기화 저장에 실패하면 화면의 기존 기록도 보존한다. 기록 읽기 실패 상태에서는 초기화를 실행하지 않는다.
- 사용자 요청으로 파일 백업/복원 UI와 Dart/native 파일 선택기 기능을 제거했다. 기기 내부 자동 저장은 유지한다.
- 앱을 삭제하면 기록도 삭제된다. Android 클라우드 자동 백업은 비활성 상태다.

## 풀이 표시 일관성

- 곱셈·분수 대소비교는 두 수식을 항상 좌우 배치하고 바로 아래 같은 방향의 답변 버튼으로 선택한다. 곱셈의 각 식은 `9832 × 33.8`처럼 한 줄로 표시하고 실제 카드 폭에 맞춰 글자만 축소한다.
- 분수 정렬은 카드와 선택 결과를 모두 A/B/C/D로 표시한다. 미선택 자리는 점으로 표시하며 1/2/3/4를 카드 식별자로 사용하지 않는다. 큰 값부터 선택, 재탭 취소, 네 장 선택 후 다음 문항 이동을 유지한다.
## 개발 및 release

```powershell
C:\tools\flutter\bin\flutter.bat test
C:\tools\flutter\bin\flutter.bat analyze
C:\tools\flutter\bin\flutter.bat build apk --release --target-platform android-arm64
```

Application ID: `com.gritpractice.grit`. 앱 버전: 1.0.0+1.

개인 release 서명키는 `.secrets/grit-release.jks`, 설정은 `.secrets/key.properties`에 있다. 두 파일은 Git 제외. 이후 업데이트에 같은 키가 필요하므로 프로젝트와 함께 안전하게 보관해야 한다. 키/비밀번호를 출력하거나 공개 저장소에 올리지 않는다.

`test/generator_test.dart`: 500 seeds × 3세트의 모든 생성 조건·채점·직렬화·난도 분포 검사.
`test/store_test.dart`: 재시작, 저장 실패, 기록 초기화, 미완료 폐기 및 완료 답안/메모 보존, 손상 파일 보존 검사.
`test/ui_test.dart`: 작은 폰·일반 폰·가로 화면의 무스크롤 표/숫자패드, 탭 입력/정렬/채점/접근성 글자 확대 검사.

실기기 결과와 최종 빌드 상태는 `VERIFICATION.md`를 확인한다. 테스트 화면과 실제 폰 화면은 구분한다.
## 풀이 안내서와 홈 (2026-10-27)

- 설정 > 풀이 안내서: 오프라인 6장/31개 풀이법/13개 확인 문제. 목차, 본문 검색, 이전/다음 풀이, 접어서 보는 정답 해설, 출처 확인 및 링크 복사.
- 초보 기준 용어 → 조건 → 단계별 예제 → 원리 → 장점 → 한계/반례 → 다음 방법으로 구성. 원문 교재/문제/그림을 복제하지 않고 직접 작성. 영상은 공개 설명/목차 확인 범위를 명시.
- 홈은 무스크롤이며 진행 중 카드와 이어풀기를 제거. 곱셈 식은 좌우 카드 안에서 각 한 줄로 유지.
- 기록/결과/안내서 등 긴 읽기 화면의 스크롤은 유지.
- 안내서 확인 문제는 학습용으로 세트 기록에 합산하지 않는다. 난수 생성 문제에 대한 자동 맞춤 해설 기능은 아니다.
- test/guide_test.dart: 메뉴/검색/읽기 이동/정답 펼침, 320dp 및 글자 1.4배의 전체 31개 설명, 주요 항등식/근접 비교 예제 검사.
