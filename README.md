## 자동 생성 규칙 v1

문제은행을 사용하지 않는다. 새 연습마다 새 난수 seed로 숫자/가림/배치를 생성하고 조건을 검사한다. seed와 실제 생성 문제를 모두 저장한다. 따라서 향후 생성기 변경 후에도 과거 문제 복습이 유지된다.

### 표

본문 크기: 3×3, 4×4, 3×3, 4×4, 5×6. 본문 정수 범위: 10~99, 0~59, -50~49, -30~29, -10~29. 합계는 실제 계산값이다. 뒤 3개 표는 양수/음수를 함께 포함한다. 가로 또는 세로 식의 미지수가 하나인 칸들을 동시 해결하는 반복이 2~4회에 끝나야 출제한다. 풀 수 없는 가림은 폐기한다.

### 곱 비교

정수 1000~10099 × 소수 1.0~99.9. 두 인수의 대소 방향은 서로 반대. 상대 차이는 abs(L-R)/max(L,R), 10~25%. 소수는 10배한 정수로 정확히 비교한다.

### 분수 비교

분자/분모 10~349, 약분하지 않음. 정확히 같은 값 제외. 상대 차이는 0 초과~14% 미만. 0~1%/1~5%/5~10%/10~14% 구간을 12/32/30/26% 확률로 선택한다. 교차곱으로 정답을 계산한다. 동일 분자/분모 허용.

### 분수 정렬

앞 3개 문항 분자/분모 10~349, 뒤 2개 10~999. 각 분수값 0.35~2.0. 최대/최소 상대 차이 17~28%, 이웃한 값 차이 3.5~14%. 같은 값 제외. 제시 순서를 섞는다.

위 범위는 제공된 예시의 통계를 바탕으로 합의한 구현 규칙이며 원본 난수식을 복원했다는 의미는 아니다.
